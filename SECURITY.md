# Security Policy

## Reporting Security Issues

Atlas is a runtime security control plane designed to protect AI agent architectures. If you discover a vulnerability in Atlas or any of its policy evaluators, please report it responsibly.

**Do NOT report security vulnerabilities through public GitHub issues.**

Instead, please email security advisories to:
* **Email**: `samuel@security.local` (or maintainer contact)

### Scope
- Bypass of Policy Decision Point (PEP) AST inspectors.
- Flaws in the SHA-256 cryptographic audit hash-chain verification.
- Indirect prompt injection filter evasion techniques.
- SSRF / Egress guard bypasses.
